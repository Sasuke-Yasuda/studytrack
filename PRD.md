# StudyTrack - Product Requirements Document

## 1. Problem

Students sometimes forget homework assignments and struggle to keep track of what they need to complete.

StudyTrack provides a simple way to organize homework assignments in one place.

## 2. Target Users

Students who want a simple way to manage their homework.

## 3. Features

1. Add a homework assignment.
2. View all homework assignments.
3. Update an existing assignment.
4. Delete an assignment.

## 4. Out of Scope

- User accounts and passwords.
- A website or graphical interface.
- Notifications and reminders.
- Cloud storage.
- Multiple users.

## 5. Technology

- Python
- JSON for saving assignments.
- Pytest for testing.
- GitHub for version control.
